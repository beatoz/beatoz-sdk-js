# SDK v2

BEATOZ SDK v2 개발 문서와 작업 기록입니다.

## 구성

- `worklog/`: 날짜별 개발 작업 디렉터리
- `worklog/_template.md`: 날짜별 요약문서 작성 템플릿
- [`worklog/2026-09-14/`](./worklog/2026-09-14/00-summary.md): SDK v2 기준선 복구 작업
- [`worklog/2026-09-23/`](./worklog/2026-09-23/00-summary.md): 테스트 계층 분리

## 작업 기록 작성 규칙

날짜별 디렉터리는 `YYYY-MM-DD` 형식을 사용합니다.

각 날짜 디렉터리의 파일은 다음 순서로 구성합니다.

- `00-summary.md`: 그날의 결론, 결정 사항, 다음 작업을 모은 요약문서
- `01-...md`, `02-...md`: 작업 순서대로 번호를 붙인 세부 문서

문서는 다음 원칙을 따릅니다.

- 문서 첫 부분에서 오늘의 결론과 독자가 얻을 정보를 먼저 설명
- 한 문서에서는 하나의 핵심 주제만 다룸
- 확인한 사실과 추측을 구분
- 명령어, 오류 메시지, 버전 등 재현에 필요한 근거를 남김
- 반복해서 사용할 수 있도록 같은 섹션 순서를 유지

일일 기록에는 다음 내용을 남깁니다.

- 오늘의 결론
- 오늘 해결하려던 문제
- 확인한 사실과 근거
- 결정한 사항
- 다음 작업

특정 오류의 원인이나 해결 절차가 길어지면 `00-summary.md`에 모두 담지 않고 같은 날짜 디렉터리의 번호가 붙은 세부 문서로 분리한 뒤 링크합니다.
