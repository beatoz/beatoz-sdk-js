# SDK v2

BEATOZ SDK v2 개발 문서와 작업 기록입니다.

## 구성

- `worklog/`: 날짜별 개발 작업 기록
- 향후 설계 문서와 문제 해결 문서는 주제별로 분리해서 이 디렉터리 아래에 추가

## 작업 기록 작성 규칙

파일 이름은 `YYYY-MM-DD.md` 형식을 사용합니다.

문서는 다음 원칙을 따릅니다.

- 문서 첫 부분에서 오늘의 결론과 독자가 얻을 정보를 먼저 설명
- 한 문서에서는 하나의 핵심 주제만 다룸
- 확인한 사실과 추측을 구분
- 명령어, 오류 메시지, 버전 등 재현에 필요한 근거를 남김
- 반복해서 사용할 수 있도록 같은 섹션 순서를 유지

일일 기록에는 다음 내용을 남깁니다.

- 오늘의 결론
- 오늘 해결하려던 문제
- 확인한 사실과 근거
- 결정한 사항
- 다음 작업

특정 오류의 원인이나 해결 절차가 길어지면 일일 기록에 모두 담지 않고 별도 문서로 분리한 뒤 링크합니다.
